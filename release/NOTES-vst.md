## WhiskerWave VST3 test build

Free and open source wavetable synth by Studio 87. This is a **test build**: the sound engine is complete and matches the web mockup in automated comparisons, but nothing has been judged by ear yet, and it has not been tried in a real DAW or on a real Mac or Windows PC by a person. It passes the automatic plugin checks (pluginval) on Linux.

**Download the one zip below.** Inside: installers for Windows (.exe), macOS (.pkg) and Linux (Flatpak extensions and a plain .vst3), the PDF manual with a numbered tour of every page, INSTALL.txt and SHA-256 sums. Everything works offline. It collects nothing.

### In this build
- The real window: the approved mockup drawn natively (Sound, Filter, Mod + Matrix, FX, Mixer, Arp, Presets), wood cheeks, resizable, info bubbles on every control, meters with a dB scale.
- Full engine: 6 wavetable oscillators (41 tables) with unison, warp, FM and ring modulation, sub, noise, 47 filter types, 16 modulators, 4 LFOs, 64 modulation routes, 8 macros, voice modes and glide, arpeggiator with step sequencer, mixer with two send buses, lookahead limiter.
- 41 effects in freely built chains on every track, the buses and the master, with band splitting. Every effect can be added as often as you like. New: Vocoder, Talk Box and Autotune (no microphone needed, they work on the synth's own sound), Dynamic EQ, Noise Gate, Tape, Granular, Freeze, Envelope Filter and Fat Cat.
- 72 factory presets and your own presets, in the same format as the web mockup.

### Not in the plugin window yet
Wave Lab (own wavetables), sample loading for the Sample and Granular oscillator modes, the grid view of the modulation matrix (there is a list), the drawing editor for Draw and LFO modulators (presets that use them play correctly), filter curve displays, undo and history, favourites, themes, mixer mute and solo, drag and drop of modulators (right click a knob instead).

Windows and macOS installers are not code signed or notarized, so the system shows a notice on first run. See INSTALL.txt.
